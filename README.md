# iCloudEMS Technical Assignment

This repository contains the complete solution for the iCloudEMS Support Engineer (AI) Technical Assignment.

## Files
- `iCloudEMS_Complete_Solution.sql`: Contains the complete, runnable SQL script for all tasks (Tasks 1-5), including data querying, bug resolution, transaction reconciliation, and detailed root-cause analyses for the theoretical API and AI troubleshooting tasks.
- `task1_university_erp_dataset.sql`: The original dataset provided for Tasks 1, 2, 4, and 5.
- `task3_reconciliation_dataset.sql`: The original dataset provided for Task 3.
- `Support Engineer AI - Candidate Technical Assignment.docx`: The original problem statement.

## Instructions
To review the assignment, please read through `iCloudEMS_Complete_Solution.sql`. The file is extensively commented and contains the methodology, findings, and corrected SQL for every scenario requested in the prompt.
